# 补充实验协议：审查问题 1、2、4

本协议在本轮新增实验运行前固定。已有旧实验结果已被查看，因此这是预先固定本轮方案的后续机制研究，不宣称独立外部盲测。旧文件不覆盖。

## 共同设置

- 沿用 Home Credit 数据和原 50/10/10/10/20 贷款记录级划分。测试标签只在全部新增训练和策略冻结后读取用于评估。
- CPU 4 线程，XGBoost hist，200 棵、depth=5，learning_rate=.05、subsample=.9、colsample_bytree=.9、reg_lambda=5，随机种子731；不根据新增测试结果改参数。
- 采样/回放种子17、29、43、61、89。静态主采样比例50%，压力比例25%；反馈5轮、初始20%，探索概率10%。
- 统一经验风险预算5%；静态验证最少批准500，反馈各信息模式统一最少100（反馈验证池更小）。经验约束不保证总体/未来风险。
- 保留全部配置、无效/不可行规则和负面结果。无可行阈值时全部拒绝、风险记缺失，不替换为0。

## A：分开样本人数和标签组成

每个保留率与种子生成四个条件，此外完整训练基线只训练一次：

1. random：与 biased 总人数相同，从原训练池均匀随机抽样。
2. group_only：与 biased 总人数、两组人数完全相同；各组内按原标签比例分层随机抽样（整数四舍五入误差不超过1条），不扭曲组内标签比例。
3. biased：薄弱组 TARGET=0 保留率50%或25%，其余全部保留。
4. corrected：biased 原样本，采用原参考集组别×标签比例纠正权重。

主比较 group_only−random 表示总量相同时群体构成变化；biased−group_only 表示总量、群体人数相同时组内标签构成变化；corrected−biased 表示已知机制下纠正。它们是不同对照，不以差值相加当作一般可加的因果分解。

均使用原完整训练池拟合的共享无标签词表、相同校准和验证集合。各静态条件训练权重归一化均值1。共41个模型。

## B：真正改变训练损失

每个样本二元交叉熵为 l_i，c_0=1，c_1=c。两组正常标签人数 n_g0：

`L(c,lambda) = (1/n) sum_i c_yi * l_i + (lambda/2) sum_g [ (1/n_g0) sum_{i:g,y=0} l_i ]`

等价样本权重 `w_i = c_yi + lambda*n/(2*n_g0) * I(y_i=0)`，训练前归一化均值1，以统一总权重与树正则尺度。通过 XGBoost 的 sample_weight 直接改变训练梯度和 Hessian，不是只改评价指标或阈值。

固定五种目标：standard=(1,0)，cost5=(5,0)，opportunity1=(1,1)，opportunity4=(1,4)，combined=(5,1)。主机会权重为1，权重4是压力分析。代价5是课堂设定，不是实际银行损失比。

机会项使两组正常标签的平均交叉熵获得等大组权重，减少某组因人数少而在目标中被忽视。它是机会导向的可加代理损失，**不是 FRR 差距硬约束，不保证机会相等**；不把差距减少当作必然结果。这也区别于 A 中估计原人群分布的权重纠正。

在 full 和五个50% biased 数据上比较。每个数据条件使用完全相同记录、特征、树参数、校准集、业务阈值选择规则。standard 复用 A 模型，新增24个模型；报告30行。报告原始与校准 Brier、AUC、两组FRR、获批率、风险、标签1的拒绝率。原始代价加权分数不能直接解释为未经校准的真实PD。

## C：验证信息来源 × 标签获取策略

每个种子将训练池随机排列成初始20%和五批到达数据。初始薄弱组正常标签保留50%。使用独立随机数、**不看标签**，预先为每条记录指定 training/calibration/validation 三种角色，概率80/10/10%。所有路径中校准/验证角色记录永远不参与树训练；只有审批后揭示的标签才能进入相应池。

两种获取路径：selected（只观察批准者）、explore_ipw（随机批准10%拒绝者，新增训练记录权重1/pi，初始权重1）。预留校准/验证记录不加IPW，以清晰研究常见的“用可见反馈直接验证”机制；IPW只作用于训练。

三种验证信息模式：

- external：第一轮更新后使用原独立校准/验证集的固定随机前缀；大小分别匹配该路径已揭示的校准/验证角色记录数。
- observed：用所有截至当轮已揭示的对应角色记录；不访问其他标签。
- frozen：仅用初始已揭示的对应角色记录，固定信息量；每轮新模型仍可在其上重选阈值。

所有六条路径共用相同初始模型及初始有偏校准/验证集；初次到达批次决策相同（探索使用相同随机数）。从第一轮更新开始只改变信息模式。每种子初始1个＋6路径×5轮＝31个模型，共155个。静态初始状态作为每条轨迹的round0，不另造训练。

external 与 observed 在各自路径内参照池等量，后续路径不同导致可见人数也可不同，因此完整轨迹比较包含自适应连锁作用。额外在每个已训练模型上，分别以 external / observed / frozen 信息重新校准和选阈值，形成同模型信息来源诊断（不反馈到主路径），分离评分固定时的信息来源效应。

角色划分、到达批次、审批概率、可见概率、可见标签、每次训练/校准/验证ID均保存。正常拒绝且未探索的标签不进入任何训练、校准或验证；只在最终封存后的全量统计分析使用。

每批反馈标签在下一批前已成熟，是理想化批次而非日历时间；仍不解决真实拒贷反事实。探索总风险单列，不宣称整个探索策略满足5%。重复使用初始/历史验证池也有适应性偏差，本实验研究其后果而非宣称这种实践无偏。

## 统计与交付

全部220个唯一模型和各轮策略冻结后，统一测试；逐记录预测与批准结果落盘。主指标薄弱组FRR，辅以比较组FRR、绝对差距、AUC、获批率、风险。所有轮次保留。

固定1000次配对bootstrap，配对测试贷款记录并重采样五个种子；区间条件于当前数据与模拟，不覆盖模型重划分、时间漂移或自然人聚类不确定性，不作多重比较校正。不以是否显著挑选报告配置。
